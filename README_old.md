# OsaLabs Hub 🚀

Bienvenue sur le **Hub OsaLabs**, le portail central regroupant tous les projets de l'écosystème OsaLabs (créé par Yanis).

🔗 **Lien en direct :** [https://www.osalabs.fr](https://www.osalabs.fr)

## 🎨 Design
Le Hub utilise un design moderne et minimaliste basé sur le **Glassmorphism**.
- **Stack :** HTML5, CSS3, JavaScript
- **Framework CSS :** Tailwind CSS (via CDN)
- **Icônes :** FontAwesome

## 🚀 Projets actuels
- **[ListenParty](https://listenparty.osalabs.fr) :** Une application web pour écouter Apple Music et Spotify en temps réel, synchronisé avec des amis.
- *D'autres projets arriveront très bientôt...*

## 🛠️ Déploiement
Le Hub est déployé sur un VPS sous Nginx.
Le code source est un simple fichier statique `index.html` qui sert de vitrine de redirection.
